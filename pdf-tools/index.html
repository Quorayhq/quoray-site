Quoray PDF Tools

PDFの操作を、ブラウザだけで。

アップロードしない。アカウントも要らない。

結合・分割といったよくあるPDF操作のために、ファイルをどこかのサーバーへ送る必要はありません。Quoray PDF Toolsシリーズは、すべての処理をブラウザの中だけで完結させる単機能の拡張機能群です。

無料枠にもアカウント登録は不要です。無料枠を超えて使い続けたい場合のみ、サブスクではなく買い切りで無制限化できます。

ラインナップ

  • PDF Merge

    複数のPDFファイルを1つに結合します。

  • PDF Split

    PDFをページ単位に分割、または指定した範囲だけを抽出します。

  • PDF Fill & Sign（準備中）

    PDFへの入力・署名に対応予定です。

Chrome・Edge・Firefox・Operaなど、対応ブラウザの拡張機能ストアで順次公開します。
