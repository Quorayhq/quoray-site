# quoray-site

Quoray公式サイトの静的サイト土台。プレーンなHTML/CSS（ビルドステップなし）で、GitHub Pagesから配信する。

## 構成

- `index.html` — トップページ（About + Ombrix紹介）
- `download/` — Download
- `privacy/` — Privacy Policy
- `terms/` — Terms of Service
- `contact/` — Contact
- `style.css` — 共通スタイル
- `CNAME` — カスタムドメイン（quoray.com）設定用
- `.nojekyll` — GitHub PagesのデフォルトJekyllビルドを無効化

現時点では骨格のみ。コンテンツは後で流し込む。
