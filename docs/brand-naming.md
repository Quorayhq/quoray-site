# ブランド命名ガイド

Quoray（旧ブランド名）がQuora Inc.の商標（日本国内、標準文字商標「QUORA」、第9類・第42類で有効）と衝突するリスクが高いことが判明し、2026年9月に「Tybright」へ改名した。この過程で確立した、今後Quoray（Tybright）が新しいブランド名・製品名を検討する際の型と検証手順を残す。

## 命名の型：アンカー1つ固定＋独占されていない固有語を探す

「完全に無名な造語」を自由連想で探すと、既存の企業・個人ブランドとの衝突を延々と繰り返すことになりやすい（短く響きの良い造語は既に世界中で使われ尽くしている）。代わりに機能したのは次の型：

- **「Ty＋固有の単語」または「固有の単語＋bright」のように、一方の要素を固定し、もう一方を探索する**
- 「Ty」はブランド保有者個人の由来を保持できる要素（人名として自然に定着した綴りでもある：Tyler、Tyson等と同様、語頭のTyは強勢のある音節では「タイ」と読まれる）
- 「bright」は実際の調査で、Samsung・Sony・Amazon・GE・Seikoなど無関係な大企業が「[固有語]+BRIGHT」の形で多数共存していることを確認済みの、**誰にも独占されていない語**

**核心の原則**：アンカーに選ぶ語は「独占されていない（多数の無関係な企業が別々の組み合わせで共存している）」ことが必須。単独の著名商標・巨大企業が支配している語（Quora、NTT、RISE等）をアンカーにすると、Quorayと同じ轍を踏む。「Merit」「Bright」のように分散所有されている語を選ぶのが安全。

**この型自体も無敵ではない**：実際に検証した際、Ty+wave・Ty+glow・Ty+flowはいずれも既存のソフトウェア/事業と衝突し、Ty+brightだけがクリーンだった（試した4組み合わせ中1組）。型は探索の出発点を絞る道具であり、個々の組み合わせごとの衝突確認は毎回省略できない。

## 検証手順（4ステップ）

新しい候補が出るたびに、以下を順番に確認する。

1. **Web実在チェック**：候補の文字列をWeb検索し、企業・製品・個人ブランドとしての先行使用がないか確認する。同業（ソフトウェア/アプリ）での使用は即除外。無関係業種での使用は許容範囲とする（商標保護は基本的に業種区分ごとであるため）。
2. **J-PlatPat完全一致確認**：[J-PlatPat](https://www.j-platpat.inpit.go.jp/)の簡易検索で候補の文字列を検索し、商標のヒット件数を確認する。0件が望ましい。
3. **核となる単語だけを抜き出した商標検索**：候補が複合語の場合、核となる実在の単語部分（例：Tybrightなら"BRIGHT"）だけで改めてJ-PlatPat検索し、**区分別の内訳**（特に第9類＝コンピュータソフトウェア、第42類＝SaaS等のソフトウェア関連サービス）を確認する。この区分に単独の支配的な権利者がいないか（多数の無関係な会社が分散して使っているか、それとも一社が独占しているか）を見る。ここがQuorayのような「完全一致ではないが著名商標の一部を含む」形の衝突を見逃さないための最重要ステップ。
4. **独立したWHOIS照会でドメインの真の空き状況を確認**：[who.is](https://who.is/)等、ドメイン検索専用サイトとは別の独立したWHOISサービスで、`<候補>.com`のWHOISデータの有無を確認する。ドメイン検索ツール（instantdomainsearch.com等）のボタン表示だけで「取得可能」と判断しないこと——ページの読み込みが完了する前の表示を見て誤判定した実例がある（候補「Solmerith」は当初取得可能に見えたが、実際は2026年7月に第三者が登録済みだった）。

## 進め方についての注意

- 複数候補を出す際は、特定の一つを繰り返し推さず、並列に提示してブランド保有者本人の反応（「しっくりくる/こない」）を尊重する。消去法で残った案を押し切る形での決定は避ける（Quorayが決定した際の失敗パターン）。
- 5〜10個試して1〜2個クリーンなものが見つかれば正常という期待値を最初に共有しておくと、無駄な焦りを避けられる。
